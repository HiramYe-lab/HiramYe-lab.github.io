Hello, World

Welcome to my corner of the internet. I’m DevRecH, and this is where I’ll be writing about the things I’m building, the problems I’m solving, and what I’m learning along the way.

Why a blog?

I’ve found that the best way to really understand something is to write about it. When you sit down to explain a concept — whether it’s a new framework, a machine learning technique, or a debugging trick — you’re forced to examine your own understanding. The gaps become obvious. The connections become clearer.

This blog is partly for myself: a way to solidify what I learn. But I hope it’s useful to you too. If something I write saves you an hour of debugging or sparks an idea for your own project, that’s a win.

What to expect

I don’t plan to stick to a single topic. My interests span a few areas:

  • Software development — languages, frameworks, tools, and patterns I find useful
  • Learning notes — things I pick up from courses, books, or just building things
  • Data and AI — machine learning, data science, and the occasional deep dive into a model or paper
  • Projects and experiments — things I build, break, and rebuild

Some posts will be deep technical dives. Others will be quick notes or reflections. I’ll write when I have something worth sharing.

Where to find me

The best place to find my code is GitHub. If you want to know more about me, check out the About page.

Posted on 2026-02-10 Edited on 2026-02-11 In Deep Learning , PyTorch

Below is a complete PyTorch nn.Module subclass implementing a GVP-GNN model, based on the paper “Equivariant Graph Neural Networks for 3D Macromolecular Structure.”

The model uses Geometric Vector Perceptrons (GVPs) for both node and edge embeddings, stacks multiple GVPConvLayer instances for message passing, and supports both equivariant and invariant prediction tasks.

""" def init( self, r_max: float = 10.0, num_bessel: int = 8, num_polynomial_cutoff: int = 5, num_layers: int = 5, in_dim=1, out_dim=1, s_dim: int = 128, v_dim: int = 16, s_dim_edge: int = 32, v_dim_edge: int = 1, pool: str = “sum”, residual: bool = True, equivariant_pred: bool = False ): """ Initializes an instance of the GVPGNNModel class with the provided parameters.

    Parameters:
    - r_max (float): Maximum distance for Bessel basis functions (default: 10.0)
    - num_bessel (int): Number of Bessel basis functions (default: 8)
    - num_polynomial_cutoff (int): Number of polynomial cutoff basis functions (default: 5)
    - num_layers (int): Number of layers in the model (default: 5)
    - in_dim (int): Input dimension of the model (default: 1)
    - out_dim (int): Output dimension of the model (default: 1)
    - s_dim (int): Dimension of the node state embeddings (default: 128)
    - v_dim (int): Dimension of the node vector embeddings (default: 16)
    - s_dim_edge (int): Dimension of the edge state embeddings (default: 32)
    - v_dim_edge (int): Dimension of the edge vector embeddings (default: 1)
    - pool (str): Global pooling method to be used (default: "sum")
    - residual (bool): Whether to use residual connections (default: True)
    - equivariant_pred (bool): Whether it is an equivariant prediction task (default: False)
    """
    super().__init__()
    
    self.r_max = r_max
    self.num_layers = num_layers
    self.equivariant_pred = equivariant_pred
    self.s_dim = s_dim
    self.v_dim = v_dim

        gvp.LayerNorm((self.radial_embedding.out_dim, 1)),
        gvp.GVP((self.radial_embedding.out_dim, 1), _DEFAULT_E_DIM,
